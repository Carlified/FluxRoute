rca2 - functional result, 2026-11-03

Function: 2-bit ripple-carry adder, s = a + b + cin (3-bit).
Clocked pads: 5 inputs (a0, a1, b0, b1, cin), 3 outputs (s0, s1, cout).
Target: 5 pipeline levels at 8 GHz
(period 125 ps); input window 78.1..185.6 ps,
chosen centre phase 131.85 ps.

--- from .cir to a viewable, verified waveform ---

Run from the repository root; the folder holding rca2.cir and rca2.tb.json
is the design folder.

  $design = "Win64/Release/output/rca2"    # examples/outputs/rca2 on a checkout
  # run the block, or "cd examples/outputs/rca2" and drop the $design prefix
  # from the file arguments below

1. Read the exported metadata:
     Get-Content $design/rca2.tb.json
   inputs a0, a1, b0, b1, cin   outputs s0, s1, cout
   frequency, pipeline levels, input window and output travel are in this file.

2. Build the stimulus for all 32 patterns and the expected outputs.
   Pattern k assigns a0, a1, b0, b1, cin to bits 4..0 of k;
   a = a0 + 2 a1, b = b0 + 2 b1, s = a + b + cin, s0,s1,cout = bits 0,1,2 of s.
     A0     = 00000000000000001111111111111111
     A1     = 00000000111111110000000011111111
     B0     = 00001111000011110000111100001111
     B1     = 00110011001100110011001100110011
     CIN    = 01010101010101010101010101010101
   expected:
     S0     = 01011010010110101010010110100101
     S1     = 00110110110010010110110010010011
     COUT   = 00000001001101110001001101111111

3. Build, simulate and decode the phase deck:
     python tools/make_tb.py --dir $design `
       --bits "a0=00000000000000001111111111111111,a1=00000000111111110000000011111111,b0=00001111000011110000111100001111,b1=00110011001100110011001100110011,cin=01010101010101010101010101010101" --slots 32 `
       --run --decode --expect "s0=01011010010110101010010110100101,s1=00110110110010010110110010010011,cout=00000001001101110001001101111111"
   0.05 ps (48100 points) crashes JoSIM (0xC0000409) on this 2422-line netlist; 0.2 ps (23459 points) is stable.

4. The decode window starts at watch + 1 period (make_tb default):
     clock send  50 ps     data launch 181.85 ps
     watch       585 ps  = clock send + 5 periods + travel
     decode      710 ps  = watch + 1 period (auto: first capture edge after the data)
     period 125 ps   slots 32   step 0.2 ps
     stop   4691.85 ps (23459 points)

5. Build the I/O-port deck for the same run and look for one pulse per bit
   on every pad:
     python tools/make_tb.py --dir $design `
       --bits "a0=00000000000000001111111111111111,a1=00000000111111110000000011111111,b0=00001111000011110000111100001111,b1=00110011001100110011001100110011,cin=01010101010101010101010101010101" --slots 32 `
       --io-nodes --out $design/rca2_io_tb.cir --run

6. View the waveforms:
     python tools/josim-plot.py $design/rca2_io_tb.csv -t stacked `
       -x $design/rca2_io_trace.html
   (open rca2_io_trace.html: clock, inputs and outputs as square waves)

--- result ---

All 32 input combinations, decoded twice on the same shared grid:
  phase traces   P(B1|XR<out>): all OK
  pad pulses     V(<out>_o): one pulse per bit, matches the expectation
  input pads     V(<in>_i): read back the stimulus exactly
The die is functionally correct at 8 GHz with the chosen centre phase.

Files:
  rca2_tb.cir/.csv/.meta.json     phase probes
  rca2_io_tb.cir/.csv/.meta.json  I/O port probes
  rca2_io_trace.html              stacked I/O trace (regenerated by step 6)
